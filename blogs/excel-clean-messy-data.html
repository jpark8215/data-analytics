How to Clean Messy Data in Excel: Steps with Tutorials

A step-by-step guide to identifying and correcting the most common data quality problems in Excel, from invisible characters and duplicate rows to inconsistent data types and misformatted dates.

Published: August 3, 2026

Raw data rarely arrives in a form that supports accurate analysis. Whether it has been exported from a CRM, downloaded from a government database, pasted together from multiple sources, or simply maintained by a team with different formatting habits over several years, most real-world spreadsheets carry defects. According to Gartner, poor data quality costs organizations an average of $12.9 million per year. IBM's research has placed the broader cost of bad data on the U.S. economy at approximately $3.1 trillion annually. Yet for many analysts, the problem manifests far more modestly: a SUM formula that returns zero, a pivot table that groups the same customer name six different ways, or a date column that refuses to sort correctly.

Excel is the tool where many of these problems are first encountered, and it provides a robust set of functions and features designed to address them. This guide walks through the most common categories of messy data and the specific Excel techniques available to resolve each one. The steps are practical and sequential, suited for analysts working with real datasets rather than sanitized training examples.

Step 1: Audit the Data Before Touching It

The first and most frequently skipped step in data cleaning is assessment. Before applying any formulas or transformations, it is worthwhile to understand the shape and character of the problems present. A quick audit prevents the frustrating scenario of spending an hour cleaning the wrong column while the actual issue lives three columns to the right.

Start by scanning each column visually. Look for inconsistently aligned values: in Excel, numbers and dates are right-aligned by default, while text is left-aligned. If a column that should contain numbers shows left-aligned entries, those cells contain text masquerading as numbers, a common cause of formula failures. Look for blank rows or columns scattered through the middle of the data, for values that seem truncated, and for any column where the same category label appears in multiple formats such as "NY," "New York," and "new york."

Beyond the visual check, Microsoft's official Excel documentation recommends using the Find and Select feature (Home tab, Find & Select, Go To Special) to locate blank cells, cells containing formulas, or cells with constants. This provides a rapid inventory of where gaps and anomalies are concentrated before any correction is attempted.

Step 2: Remove Extra Spaces with TRIM

Extra spaces are among the most prevalent and least visible data quality problems. A customer name with a leading space will not match the same name without one, meaning a VLOOKUP will fail and a pivot table will treat them as separate entities. They arrive from copy-paste operations, web scraping, PDF extractions, and database exports.

Excel's TRIM function removes leading and trailing spaces from a text string, and reduces any sequence of multiple internal spaces down to a single space. According to the official Microsoft support documentation, its syntax is straightforward:

=TRIM(text)

Tutorial: Suppose column A contains customer names with irregular spacing. In cell B2, enter:

=TRIM(A2)

Copy that formula down through the entire column. The result in column B will be the cleaned names. Once verified, select the entire B column result, copy it, then use Paste Special (Ctrl + Alt + V, then V for Values) to paste only the values over column A. Delete the helper column B when finished.

One important limitation: TRIM does not remove non-breaking spaces, which carry the Unicode character value 160 (CHAR(160)) and frequently appear in data copied from web pages. Those require a different approach covered in Step 4.

Step 3: Remove Non-Printable Characters with CLEAN

Some data, particularly that exported from legacy systems or imported from certain database formats, contains non-printable characters. These are the first 32 characters in the ASCII character set (values 0 through 31) and include items such as line breaks, carriage returns, and low-level control codes. In a spreadsheet they may appear as small squares or rectangles, or they may be entirely invisible while still causing formula errors or sorting anomalies.

Excel's CLEAN function strips these characters from a text string. Its official syntax, per Microsoft's function reference, is:

=CLEAN(text)

Tutorial: If column A contains imported text with embedded line breaks or invisible characters, in cell B2 enter:

=CLEAN(A2)

This removes any non-printable ASCII characters from the string. As with TRIM, copy the formula down and paste values back once the output is confirmed correct.

TRIM and CLEAN are frequently applied together in a single nested formula, since extra spaces and non-printable characters often co-exist in the same imported dataset.

Step 4: Handle Stubborn Characters with SUBSTITUTE

When TRIM alone fails to remove certain spaces, the problem is usually the non-breaking space (CHAR(160)). This character looks identical to a standard space but is not recognized as whitespace by TRIM. The SUBSTITUTE function resolves this by replacing every instance of a specified character with another character of your choosing.

The official syntax from Microsoft's support documentation is:

=SUBSTITUTE(text, old_text, new_text, [instance_num])

The optional fourth argument, instance_num, allows replacement of a specific occurrence rather than all occurrences. When omitted, all instances are replaced.

Tutorial: The most powerful general-purpose cleaning formula combines all three functions. In cell B2, enter:

=TRIM(CLEAN(SUBSTITUTE(A2, CHAR(160), " ")))

This formula works in three layers. First, SUBSTITUTE replaces every non-breaking space (CHAR(160)) with a standard space. Second, CLEAN removes any remaining non-printable ASCII characters. Third, TRIM removes all leading, trailing, and duplicate internal spaces from whatever remains. This combination handles the majority of text-based cleaning problems in a single step.

SUBSTITUTE is also useful for removing characters that should not appear at all. For example, to strip every dollar sign from a column of currency values imported as text, use =SUBSTITUTE(A2, "$", ""), replacing the unwanted character with an empty string.

Step 5: Find and Remove Duplicate Rows

Duplicate records are a structural problem rather than a character-level one. They arise when data is appended from multiple sources, when a process runs twice without a deduplication step, or when a team manually combines datasets. A duplicate row does not cause a formula to fail, but it silently inflates counts and totals, producing reports that look plausible but are factually incorrect.

Excel provides a built-in tool for this under the Data tab. However, it is permanent by default, so a copy of the original data should always be preserved before proceeding.

Tutorial: Remove Duplicates (built-in tool)

  1. Select any cell within your data range.
  2. Navigate to the Data tab and click Remove Duplicates in the Data Tools group.
  3. In the dialog that appears, select which columns should be used to define uniqueness. If every column must match for a row to be considered a duplicate, select all columns. If only certain fields (such as email address or order ID) define uniqueness, select only those.
  4. Click OK. Excel will display a message confirming how many duplicate values were removed and how many unique values remain.

For a non-destructive alternative, the COUNTIF function can identify duplicates without removing them. In a helper column, enter =COUNTIF($A$2:$A$100, A2) and copy it down. Any value greater than 1 indicates a duplicate. This approach allows review of the duplicates before permanent deletion, which is particularly useful when there is any ambiguity about which definition of "unique" applies to the dataset.

Step 6: Fix Inconsistent Text Formatting with UPPER, LOWER, and PROPER

Inconsistent capitalization is a frequent consequence of data entered by multiple people over time. "New York," "new york," and "NEW YORK" will be treated as three separate values by any function that performs an exact match, including VLOOKUP, SUMIF, and pivot tables. Standardizing case is one of the simpler cleaning operations but one that has a substantial effect on analysis accuracy.

Excel provides three functions for this purpose, each documented in Microsoft's official function reference:

  • =UPPER(text) converts all characters to uppercase.
  • =LOWER(text) converts all characters to lowercase.
  • =PROPER(text) capitalizes the first letter of each word and lowercases the rest.

Tutorial: If column A contains city names with inconsistent casing and you want to standardize them to title case, in cell B2 enter:

=PROPER(A2)

Copy down, verify the results, then paste values back over the original column. Note that PROPER can produce unexpected results with abbreviations or proper nouns that contain lowercase letters mid-word, such as "McDonald" becoming "Mcdonald." Review the output for such cases.

Step 7: Correct Data Type Mismatches

One of the most consequential and least obvious forms of messy data is a value stored in the wrong data type. A column of order amounts stored as text will return zero in a SUM formula. A date column stored as text will not sort chronologically and will not work in date arithmetic. Excel's default behavior of right-aligning numbers and dates while left-aligning text provides the first diagnostic clue.

The ISNUMBER function provides a programmatic check. Entering =ISNUMBER(A2) returns TRUE if Excel recognizes the cell's value as numeric and FALSE if it is stored as text. For a date column, =ISNUMBER(A2) also returns TRUE because Excel stores dates internally as serial numbers.

Tutorial: Convert text-stored numbers to actual numbers

  1. If the column shows the small green triangles in the upper-left corner of cells, select the entire column, click the warning icon that appears, and choose Convert to Number. This is the fastest method when Excel has already flagged the issue.
  2. Alternatively, in a helper column, use the VALUE function: =VALUE(A2). This converts a text string that looks like a number into an actual numeric value. Copy the formula down, paste values, and replace the original column.
  3. For an entirely non-formula approach, select the column, go to Data, click Text to Columns, proceed through the wizard without changing any delimiter settings, set the column data format to General, and click Finish. Excel will re-evaluate each cell and convert recognizable numbers automatically.

Tutorial: Fix dates stored as text

  1. Select the column containing the text-formatted dates.
  2. Go to Data and click Text to Columns.
  3. Choose Delimited and click Next.
  4. Uncheck all delimiter options and click Next.
  5. Under Column data format, select Date and choose the format that matches the current date layout in the column (e.g., MDY, YMD).
  6. Click Finish. Excel will convert the text dates into genuine date values. Format the column as a Date type via the Home tab to confirm the output is correct.

Step 8: Use Flash Fill for Pattern-Based Cleanup

Flash Fill is a feature introduced in Excel 2013 that detects patterns from examples provided manually and applies those patterns to the rest of a column automatically. It does not require formulas and is particularly effective for reformatting data that follows a consistent but non-standard structure, such as splitting a full name column into first and last name columns, reformatting phone numbers, or extracting a domain from an email address.

Tutorial: Suppose column A contains entries like "Smith, John" and you need to extract only the last name into column B.

  1. In cell B2, manually type the expected result: Smith.
  2. Press Enter to move to B3.
  3. Press Ctrl + E to invoke Flash Fill. Excel will detect the pattern from the example and fill the remaining cells automatically.

Always review the Flash Fill output carefully before accepting it. The pattern detection is probabilistic and can produce incorrect results when the source data is not sufficiently consistent.

Step 9: Handle Blank Cells Deliberately

Blank cells are not inherently a problem, but they become one when they are not handled deliberately. A blank in a date column may mean "not yet completed," "data not collected," or "this row does not apply." Treating all three meanings identically leads to incorrect aggregations. Before deciding how to handle blanks, it is necessary to understand why they exist.

Excel's Go To Special feature (Home tab, Find & Select, Go To Special, Blanks) selects all blank cells in the current range simultaneously. This allows bulk entry of a placeholder value, deletion of rows with missing key fields, or targeted review of each gap. The appropriate action depends entirely on the analytical context.

For situations where blanks in a numeric column should be treated as zero, the IF and ISBLANK functions provide a formula-based solution: =IF(ISBLANK(A2), 0, A2). This returns zero if the cell is blank and the original value if it is not, without modifying the source data.

Step 10: Use Power Query for Repeatable, Large-Scale Cleaning

The functions and features described in the preceding steps are effective for one-time cleaning of a specific dataset. However, when the same cleaning operations must be applied repeatedly as new data arrives, or when the dataset is large enough to make manual review impractical, Power Query is the appropriate tool. Available natively in Excel 2016 and later versions, and accessible through the Data tab under Get Data or From Table/Range, Power Query records each transformation step and can re-apply them to refreshed data automatically.

Tutorial: A basic Power Query cleaning workflow

  1. Select any cell within your data range and press Ctrl + T to convert it to a formal Excel Table. Give it a meaningful name in the Table Design tab.
  2. With the table selected, go to the Data tab and click From Table/Range. The Power Query Editor opens.
  3. To remove duplicate rows: select the columns that define uniqueness, then on the Home tab click Remove Rows and choose Remove Duplicates.
  4. To remove blank rows: on the Home tab, click Remove Rows and choose Remove Blank Rows.
  5. To trim whitespace from text columns: right-click a column header, choose Transform, and select Trim.
  6. To fix data types: click the data type icon at the left of each column header and select the correct type (Text, Whole Number, Date, etc.).
  7. When all steps are complete, click Close & Load on the Home tab. The cleaned data is returned to a new sheet in Excel.

All applied steps are recorded in the Applied Steps pane on the right side of the editor. When the source data is updated, right-clicking the query in the Queries & Connections pane and selecting Refresh re-runs every step automatically against the new data.

Power Query is particularly well-suited to data cleaning workflows that must be documented, audited, or shared with colleagues, because the applied steps function as an explicit, reviewable record of every transformation performed. This transparency addresses one of the chronic weaknesses of formula-based cleaning, where the logic is distributed across hundreds of cells and difficult to reconstruct after the fact.

After Cleaning: Verify Before You Trust

No cleaning process should be considered complete without a verification step. After applying corrections, it is worth running a set of sanity checks against the cleaned data. These include confirming that row counts align with expectations, that the range of values in key numeric columns falls within plausible bounds, that all cells in columns designated as required are populated, and that formerly inconsistent categories have consolidated to the expected number of distinct values.

The COUNTA function counts all non-empty cells; COUNTBLANK counts empty ones. COUNTIF tallies how many times each value appears in a column and is useful for confirming that category standardization has produced the correct number of distinct entries. A pivot table over a key dimension column is often the fastest way to verify that consolidation efforts were effective, because it immediately reveals any residual variants that were not addressed by the cleaning formula.

It is also worth preserving the original uncleaned data, either in a separate sheet or in a separate file, before committing any cleaning changes. Data cleaning involves judgment calls about how to interpret ambiguous values, and those judgments may need to be revisited if downstream analysis produces unexpected results. A recoverable original is far preferable to attempting to reconstruct source data after the fact.

Conclusion

Cleaning data in Excel is not a single action but a sequence of diagnostic and corrective steps, each addressing a specific category of quality problem. The functions and tools covered here, TRIM, CLEAN, SUBSTITUTE, Remove Duplicates, PROPER, VALUE, Text to Columns, Flash Fill, and Power Query, collectively address the vast majority of issues encountered in real-world spreadsheets. Each has a defined scope and a set of limitations that the preceding steps have attempted to make explicit. The underlying discipline, however, remains constant regardless of which tool is used: understand what is wrong before correcting it, apply corrections in a verifiable and reversible way, and confirm that the result is actually what the analysis requires. Data cleaning done carefully is not overhead; it is the foundation on which every subsequent conclusion depends.
